AmneziaVPNустановка, обновление ключа и маршрутизация

Интерфейс AmneziaVPN одинаковый на телефоне и компьютере, поэтому этот гайд подходит для всех устройств. Скриншоты сделаны в мобильной версии приложения.

Скачать AmneziaVPN Скачать список российских сайтов
Установка4 шага
1. Скопируйте ключ

На этой странице в блоке AmneziaVPN нажмите «Скопировать ключ». При первом запуске приложения нажмите «Приступим».

2. Вставьте ключ

Нажмите «Вставить», затем «Продолжить».

3. Подключитесь

На экране нового соединения нажмите «Подключиться».

4. Готово

Сервер добавлен. Включайте VPN большой кнопкой «Подключиться».

Обновление ключа3 шага
1. Откройте серверы

На главном экране нажмите стрелочку справа от названия VPN в нижней части экрана.

2. Откройте настройки

В меню серверов нажмите шестерёнку рядом с нужным сервером.

3. Удалите старый сервер

Нажмите «Управление», затем «Удалить сервер из приложения» и «Продолжить». После этого повторите установку с новым ключом.

Маршрутизация сайтов5 шагов
1. Откройте меню

На главном экране нажмите строку «Раздельное туннелирование ...».

2. Выберите сайты

Откройте «Раздельное туннелирование сайтов».

3. Импортируйте список

Сначала нажмите выше кнопку «Скачать список российских сайтов». В AmneziaVPN нажмите три точки, выберите «Импорт» и выберите скачанный файл amnezia-ru-sites.json.

4. Замените список

В окне импорта нажмите «Заменить список с сайтами».

5. Проверьте режим

Тумблер сверху включён, режим: «Адреса из списка не должны открываться через VPN». Готово.

Маршрутизация приложенийтолько телефон

Добавьте российские приложения, чтобы они работали без VPN, пока остальной трафик идёт через VPN.

1. Выберите приложения

Нажмите «Раздельное туннелирование ...», затем «Раздельное туннелирование приложений».

2. Добавьте нужные

Нажмите плюсик и выберите Max, VK, Госуслуги, 2ГИС, Mir Pay, Ozon, Wildberries, банки, Яндекс и похожие сервисы.

3. Проверьте режим

Нажмите «Добавить выбранные». Должно быть: «Приложения из списка не должны работать через VPN», тумблер включён.
