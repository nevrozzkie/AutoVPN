# AutoVPN 0.2.0 — Android и TV

Небольшой native Android companion для телефонов и TV без постоянного сервиса и собственного VPN-движка.
Android 8+; без native библиотек, подходит для ARMv7/ARM64. Русский интерфейс, D-pad. Поддерживаются портретная и горизонтальная ориентации:
на узком экране кнопки привязки стоят друг под другом, содержимое прокручивается.

1. Установить APK и открыть **AutoVPN** из launcher.
2. Нажать **Привязать AutoVPN**, ввести существующую личную HTTPS-ссылку
   `/client/{token}` или `/sub/{token}`. Для телевизора рекомендуется отдельный VPN client.
3. **Добавить в Amnezia** читает актуальный `/amnezia-key/{token}` и передаёт ключ
   через явный `ACTION_SEND text/plain` в `org.amnezia.vpn.ImportConfigActivity`.
4. **Добавить в NekoBox** проверяет актуальную `/sub/{token}`, затем открывает
   `sn://subscription?url=…&name=…` явным intent в NekoBox. Каждому импорту присваивается
   название с временем. NekoBox сам скачивает подписку после подтверждения.

Обе кнопки добавляют новые записи. Старые не удаляются. Повторное нажатие после
завершённого импорта может создать дубликат. Companion сообщает «передано», а не
«применено»: подтверждение и результат импорта принадлежат VPN-клиенту.
Автоподключение, переключение VPN и root не используются. Одновременно активен один VPN.

Используется существующий клиентский API AutoVPN, Router API и серверная БД не меняются.
Это привязка ссылкой клиента, **не регистрация в реестре Router**: нет отдельного device
credential, heartbeat и apply-report. Эти возможности можно добавить отдельным этапом.

## Сборка

JDK 17+, Android SDK 36. Включён Gradle wrapper 9.4.1, AGP 9.1.1:

```sh
cd android-tv
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Для сайта используется подписанный release APK:

```sh
./gradlew :app:testDebugUnitTest :app:lintRelease :app:assembleRelease
# Из корня репозитория, после проверки подписи apksigner:
cp android-tv/app/build/outputs/apk/release/app-release.apk app/static/downloads/AutoVPN-0.2.0.apk
```

Конфигурация подписи по умолчанию читается из `data/android-signing/signing.properties`
в корне репозитория (либо из абсолютного пути `AUTOVPN_SIGNING_PROPERTIES`):

```properties
storeFile=/absolute/private/path/release.jks
storePassword=YOUR_PRIVATE_PASSWORD
keyAlias=autovpn
keyPassword=YOUR_PRIVATE_PASSWORD
```

Без файла подписи Gradle создаст unsigned release: такой файл не публиковать.
Локальная сборка 0.2.0 подписана новым ключом из `data/android-signing/`.
Сохраните закрытую резервную копию всего этого каталога: этот же ключ нужен для
последующих обновлений. Каталог исключён из Git; пароль и ключ не входят в APK
и не раздаются через сайт. Не коммитить keystore или signing.properties.

У старого debug-прототипа AutoVPN TV 0.1.0 другая подпись. Для перехода на release
его нужно удалить и установить 0.2.0, затем повторить привязку. Сами VPN-профили
в AmneziaVPN и NekoBox сохраняются. Имя пакета остаётся `org.autovpn.tv`.
На пользовательской странице сайта есть ссылка на APK и инструкция по привязке.

## Секреты и сеть

- Ссылка хранится зашифрованно AES-GCM; ключ в Android Keystore, backup выключен.
- В UI отображается только host, ввод ссылки защищён от снимков экрана.
- Только HTTPS с системной проверкой сертификата. Redirects выключены, body ≤256 KiB,
  ограничены timeout и время чтения. Секреты/ответы не логируются companion-приложением.
- Клиентская ссылка является bearer-секретом; не использовать административные ссылки.
- При передаче конфигурации целевое приложение получает её и само определяет своё
  хранение/логирование. Нельзя обещать отсутствие секрета в системных логах intent.
- «Отвязать» удаляет локальную привязку, но не отзывает токен на сервере и не удаляет
  уже импортированные профили.

Проверяемые версии: Amnezia 5.0.3.0, NekoBox 1.4.2. Проверка настоящего импорта требует
личной клиентской ссылки; тесты используют только фиктивные значения.
