# Controller 0.14.1: восстановление bootstrap

Релиз `router-v0.14.1-openwrt-25.12.5-r1` исправляет две ошибки,
которые не выявляла прежняя проверка ucode через JavaScript:

- `require()` ucode не допускает дефис в имени модуля. Модули
  `network_transaction`, `direct_zapret`, `setup_policy` теперь используют
  допустимые имена; APK и все вызовы обновлены вместе.
- В `network-helper.uc` JavaScript-оператор `throw` заменён на catchable `die()`.

Также ручное обновление из LuCI теперь читает настроенную APK-архитектуру,
а не generic `apk --print-arch`, и сверяет её с метаданными установленного ядра.

## Проверка артефакта

Controller собран OpenWrt SDK и подписан прежним ключом. Для пакета
`autovpn-controller-0.14.1-r1.apk`:

- размер APK: 93 709 байт;
- `installed-size` из APK metadata: 363 110 байт;
- SHA-256: `6090db063a20acddc6d09a290bb99ebbb33436cd293a9c6636ac1dcec0227ae0`.

Подпись проверена SDK `apk verify`. Из подписанного APK извлечены файлы:
все 14 модулей загрузились настоящим ucode версии исходников
`2026.01.16~85922056`, все libexec-обработчики и rpcd-обработчик
скомпилированы им без исполнения сетевых операций. Повторяемая проверка:

```sh
AUTOVPN_UCODE_BINARY=/path/to/sdk/staging_dir/hostpkg/bin/ucode \
AUTOVPN_UCODE_MODULES=/path/to/sdk/staging_dir/hostpkg/lib/ucode \
sh openwrt/tests/run-native-ucode.sh /path/to/extracted-controller
```

Host ucode не содержит ubus/UCI: эти импорты оставлены динамическими при
компиляции. Это не тест работы Wi-Fi, UCI, firewall или VPN на устройстве.
Роутер при подготовке исправления не изменялся.

## Узкий путь ремонта

Опубликованный `repair-bootstrap.sh` предназначен только для установки
0.14.0, остановившейся **до** привязки сайта и создания сетевой транзакции.
Он проверяет сохранённый ключ, репозиторий, закреплённый manifest и подпись,
а затем допускает offline APK-план с единственным обновлением controller.
AmneziaWG, ядро, feeds, существующий receipt и UCI скрипт ремонта не меняет.
После обновления освобождаются locks и запускается установленный мастер Wi-Fi;
именно мастер по подтверждению пользователя меняет Wi-Fi.

Требуется 2 МиБ свободного `/overlay` и 20 МиБ `/tmp`, а не полный бюджет
первой установки. Если controller уже обновлён, но мастер ещё не начал
сетевую транзакцию, команду можно повторить. При наличии конфигурации сайта,
credentials, journals или maintenance gates ремонт откажется работать.
Не удаляйте эти файлы, чтобы обходить проверку.
