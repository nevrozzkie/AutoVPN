# Установочный релиз r2 — 2026-09-06

Тег: `router-v0.14.0-openwrt-25.12.5-r2`. Это предварительный выпуск для первой
проверки на устройстве, а не подтверждение работающих туннелей на реальной сети.
Бинарный r1 остаётся без изменений; r2 добавляет готовый `install.sh` и manifest.

## Проверки

- Три APK собраны из `bf0a1f2`; соответствующие рецепты и устанавливаемые файлы
  совпадают с вошедшими в `main` через PR #1. Подробности: [SDK build](awg-sdk-build.md).
- Производственный `prepare-release.py` запущен с настоящим APK tools 3.0.5
  из SDK: проверены подписи, metadata, архитектура и точная зависимость kernel.
- Официальные feeds проверены ключом `openwrt-25.12.pem` из закреплённого
  OpenWrt keyring `f0670054`. SHA256 исходного keyring-архива:
  `a8e0c09678109c576a54ed5101ac83131015533da899c10d9e276c200cf97b1b`.
- Настоящий `apk add --simulate` разрешил все зависимости в отдельной пустой
  базе под `aarch64_cortex-a53`: 86 пакетов, 38,1 МиБ, включая базовую систему.
  Это проверка solver без установки и выполнения scripts; не копия установленной
  базы роутера. На роутере большая часть базовых зависимостей уже присутствует.
- Повторно пройдены 29 тестов установщика и подготовки release, без пропусков.
  Эти тесты используют изолированные fixtures, а не живой роутер.

## Бюджет места

По ранее прочитанным 159 установленным именам пакетов и официальным каталогам
требуются 24 дополнительных официальных пакета: 33 358 560 байт файлов и
12 013 774 байта APK. Три custom APK занимают 163 826 байт при скачивании и
535 296 байт установленных файлов. С zapret и текущей RU-базой известная
полезная нагрузка составляет **34 529 370 байт (32,930 МиБ)**.

Manifest требует **38 МиБ (38 912 КиБ) свободного `/overlay`**: около 5,07 МиБ
сверх полезной нагрузки на метаданные, округление, конфигурацию и рабочий запас.
Ранее на устройстве было 42 888 КиБ свободно. Это расчётный порог с запасом;
фактический post-install `df`, поведение UBIFS и будущие обновления не измерены.

Для `/tmp` требуется **64 МиБ**. Известные APK занимают около 11,61 МиБ,
архив zapret — ещё 4 320 347 байт. Остальное оставлено для индексов feeds,
распаковки, служебных файлов и запаса. Это не гарантия свободной RAM при любой
нагрузке; установщик zapret отдельно проверяет доступную память.

## Границы проверки

Роутер не изменялся. Установка APK, загрузка AWG-модуля, создание Wi-Fi,
handshake двух туннелей и работа Discord зависят от проверки на устройстве.
`--check` самого установщика скачивает данные в RAM, проверяет совместимость,
подписи, место и APK-план; отдельный zapret installer запускается только после
установки APK. Вся процедура не является единой атомарной транзакцией.

Установка и дальнейшая привязка к Router API описаны в [руководстве](installation.md).
