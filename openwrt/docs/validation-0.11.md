# Локальная проверка AutoVPN 2.0 / controller 0.11.0

Дата: 2026-09-05. Ветка: `codex/autovpn-2.0`. Коммиты только локальные,
без push, публикации assets, деплоя сайта и изменения роутера.

## Пройдено

- Полный серверный pytest: **290 passed, 1 skipped** (macOS, Python 3.14).
- `openwrt/scripts/check.sh`: **272 passed**, без пропусков при заданном
  `AUTOVPN_SING_BOX`; shell/JS/JSON проверки и `git diff --check` успешны.
- Реальный sing-box 1.13.18 Darwin arm64 проверил генерируемые конфиги legacy,
  VPN и VPN+zapret для auto/VLESS/Hysteria2. Linux-only routing marks и kernel
  AmneziaWG этим запуском не проверяются.
- Тесты покрывают раздельные runtime/Auto/Ping all, API-only дополнительный
  AWG peer, совместимость старых подписок и ETag, миграцию schema 3 → 4 и rollback,
  изоляцию отказов, подтверждение закрытия сетей, WAN-only direct-zapret,
  WPA2 bootstrap четырёх SSID, установку закреплённого upstream zapret2,
  reset/rebind и поведение LuCI на отложенных/ошибочных ответах.

Host-тесты ucode исполняют совместимый JS subset с эмуляцией окружения. Они не
заменяют запуск в OpenWrt и не доказывают синтаксис/поведение Linux nftables,
nfqws2, netifd, procd или драйвера Wi-Fi.

## Не завершено — выпуск пока не готов к установке

1. Linux SDK-сборка, подпись APK и измерение полного набора зависимостей.
   В текущем macOS-окружении нет Linux SDK/runtime. Старый официальный AWG feed
   нельзя считать совместимым с ядром 6.12.94 без доработки и реальной сборки.
   Проверенные входные данные и ограничения: [build inputs](build-inputs-25.12.5.md).
2. Проверка nfqws2/nftables и реальной маршрутизации/отказов на OpenWrt.
   Установка и изменения роутера не разрешены. Проверка наличия `loadstring`
   выполнена по read-only SSH; передача исходников для компиляции в RAM
   заблокирована защитой как неавторизованная передача приватного кода и не выполнялась.
3. Публикация подписанного GitHub Release и серверный canary/deploy.
   Ничего не опубликовано и не развёрнуто. Шаблон installer не является готовой
   ссылкой установки. Сначала нужен сервер с `/api/v2/router/snapshot/dual`.

Нет подтверждённого утверждения о финальном размере во flash, скорости VPN,
эффективности стратегий DPI у провайдера или готовом AWG kmod под этот роутер.
