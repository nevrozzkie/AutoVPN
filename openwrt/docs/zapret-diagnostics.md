# Диагностика zapret в LuCI

Страница диагностики zapret не входит в текущий активный LuCI-сценарий и скрыта.
Пользователю доступны только базовый Wi-Fi и VPN-сеть `-в`. Этот документ описывает
сохранённый legacy/API contract для совместимости; backend не следует считать
включённым только потому, что файлы диагностики присутствуют в пакете.

Страница **Services → AutoVPN → Zapret diagnostics** помогает вручную подобрать
стратегию под конкретного провайдера. Она не меняет исправный VPN сама и не запускает
произвольные команды из панели или с AutoVPN-сервера.

## Режимы

- **Direct YouTube/Discord** временно останавливает только direct-zapret, запускает
  закреплённый `blockcheck2` v1.0.5 для `www.youtube.com` и `discord.com` по IPv4/TCP
  и возвращает только стратегию, общую для обоих доменов. QUIC принудительно не
  проверяется: при применении такого результата UDP/443 в сети `-з` блокируется,
  чтобы браузер повторил соединение по TCP. Голос Discord проверяется отдельно
  после применения; HTTPS blockcheck не доказывает работу медиа.
- **VLESS transport** перебирает только четыре встроенных TLS-рецепта на внешнем
  соединении VLESS сети `-вз` и делает реальную HTTPS-проверку через её SOCKS-вход.
- **Hysteria2 transport** аналогично перебирает три встроенных UDP-рецепта.

Временная проверка VLESS/Hysteria2 может кратко прервать соединения только сети
`-вз`. Обычная сеть, `-в` и AmneziaWG не переключаются. После завершения, отмены
или ошибки восстанавливается сохранённый runtime-план.

## Использование

1. Сначала убедиться, что движок установлен в **Settings → Zapret2 engine**.
2. Выбрать один scope и нажать **Start diagnostics**. Одновременно выполняется
   только одна диагностика; maintenance и обновление контроллера имеют приоритет.
3. Дождаться состояния `ready`. `No candidates` означает, что встроенный набор не
   дал общего рабочего результата, а не что блокировки нет.
4. Выбрать возвращённый Candidate ID и нажать **Apply candidate**. Это единственный
   шаг, который сохраняет UCI-настройку. При ошибке применения возвращается прежняя.
5. Проверить сеть реальным клиентом: YouTube-видео, Discord-сайт, голосовой и
   видеозвонок. Для VLESS/Hysteria2 дополнительно использовать **Ping all: VPN + zapret**.

Задача ограничена пятью минутами и хранит рабочие файлы только в root-only `/tmp`.
Загружается закреплённый официальный архив zapret2 с проверкой SHA-256. Кнопка
**Cancel** ставит запрос отмены; очистка upstream firewall/process state выполняется
его штатным обработчиком сигналов, после чего AutoVPN восстанавливает свою lane.
