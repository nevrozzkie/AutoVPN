# Обслуживание AutoVPN через LuCI

Версия приложения: 0.7.0. Путь: **Services → AutoVPN → Maintenance**.
Все операции требуют авторизованную LuCI-сессию с правом записи AutoVPN.
Секреты передаются только через приватный stdin RPC-helper и сохраняются в файле
с правами `0600`. В UCI, argv и ответе RPC токена нет. Для ввода токена нужен HTTPS
LuCI или доверенная проводная сеть: авторизация не защищает обычный HTTP от перехвата.

## Привязка и сброс

- **Replace token**: вставить новый токен того же Router ID, заранее созданный
  в админке сайта. Меняется только локальный credential; серверный токен эта
  кнопка не выпускает и не отзывает. Текущий VPN и настройки сохраняются.
- **Rebind router**: указать адрес сайта, Router ID и токен; ввести `REBIND`.
  Прежние VPN-конфигурации и журнал контроллера удаляются после закрытия трафика.
  Wi-Fi, WAN/LAN и локальная политика сохраняются. Затем нажать **Resume AutoVPN**.
- **Reset AutoVPN only**: ввести `RESET`. Удаляются привязка, токен, сохранённые
  VPN-профили и журнал контроллера; политика возвращается к значениям по умолчанию.
  Это **не factory reset**: `/etc/config/network`, `wireless`, `dhcp`, `firewall`,
  Wi-Fi-имя/пароль, журнал и резервные копии сетевой транзакции не удаляются.
  Для нового запуска заполнить привязку, выполнить **Rebind**, затем **Resume**.

Сброс и перепривязка требуют подтверждённых управляемых сетей. Незавершённую
сетевую транзакцию нужно сначала завершить или восстановить на странице Networks.
Операции не выполняются при несохранённых изменениях UCI, нестандартных путях
секретов/состояния или пользовательских адаптерах.

## Обновление приложения

Первичный установщик сохраняет локальный публичный ключ и сведения о доверенном
GitHub-репозитории. Панель не принимает произвольный URL загрузки и не запускает
скачанный shell-скрипт.

1. Ввести опубликованный GitHub release tag и нажать **Check release**.
2. Проверить предложенную версию и нажать **Install checked version**.
3. Дождаться `ready`; LuCI может кратковременно переподключиться при обновлении rpcd.
4. Нажать **Resume AutoVPN**.

Проверка и установка начинаются только по кнопке: расписания и автообновления нет.
Проверка выпуска не прерывает VPN. Перед самой установкой трафик закрывается,
а контроллер отключается. Обновляется только подписанный `autovpn-controller`:
не прошивка, не загрузчик, не ядро и не AmneziaWG-модуль. Если выпуск требует
изменения других пакетов или не совпадает OpenWrt/kernel ABI, операция отклоняется.

После сбоя или перезагрузки маркер обслуживания сохраняется; простой запуск
службы, очередной poll и восстановление старого журнала не открывают VPN.
Не удаляйте lock-файлы вручную: это обходит проверки восстановления.
После ошибки установки можно вручную проверить и установить тот же подписанный
выпуск либо более новый. Если APK уже записал эту версию и предлагает только
пустую транзакцию, панель отклоняет её с `update_recovery_needs_newer_release`:
нужен более новый подписанный выпуск. Пустая транзакция не считается восстановлением
файлов после сбоя. Откат/принудительная переустановка произвольных APK не реализованы.

## Что ещё не подтверждено

Host-тесты используют имитации UCI/APK/сети; реальный sing-box проверяет только
синтаксис сформированной конфигурации. Нужны сборка подписанного APK и проверка
на WR3000S v1: установка, обновление, перезагрузка во время обслуживания,
повтор операции после ошибки и доступность исходной административной LAN/SSID.
Публичного релиза и рабочей опубликованной команды установки пока нет.
