# Пользовательские приложения AutoVPN

## Установка PWA

Откройте личную страницу `/client/{token}` по HTTPS. В поддерживающем установку
браузере появится кнопка «Установить AutoVPN». Через меню браузера также можно
выбрать «Установить приложение» / «Добавить на главный экран». На iPhone и iPad
откройте страницу в Safari: «Поделиться» → «На экран Домой».

Установленная PWA открывает именно личную страницу клиента в отдельном окне.
Manifest выдаётся только включённому клиенту, имеет индивидуальные `id` и
`start_url` и общий scope `/client/`. Админка и якорные страницы вне этого scope.
Service worker не кеширует HTML, клиентские ключи, подписки и ответы действий.
При отсутствии сети показывается нейтральный экран с повторной попыткой;
отключённый клиент получает текущий ответ сервера, а не сохранённые настройки.
API смены IP и все проверки прав используются те же, что в обычном браузере.

PWA управляет подключениями и сменой IP через сайт. Сам VPN работает в выбранном
VPN-клиенте. Доступ через HTTP на обычном домене не позволяет установить PWA;
localhost можно использовать для разработки.

Документация платформы: [установка PWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable),
[scope service worker](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerContainer/register).

## Компактная личная страница

В разделе «Статус VPN» находятся IP, время обновления конфига и одно общее время
последней проверки. Показывается самый поздний момент из доступных проверок
включённых протоколов, с учётом часового пояса. Технические результаты остаются
в админке; отдельные отметки транспорта и пояснения handshake в личной странице
не показываются.

Статусы: «ОК», «Не работает», «Не проверено». «ОК» требует полноценной проверки
VLESS или туннеля Hysteria. Доступность TCP-порта, отправка UDP-пакета и работа
сервиса не считаются подтверждением VPN. Текущая глубокая проверка Amnezia
подтверждает конфигурацию peer, а не handshake, поэтому даже при её успехе в
личной странице остаётся «Не проверено».

Ссылки, длинный ключ и инструкции ручного подключения скрыты в раскрываемых
пунктах рядом с кнопками импорта. Внизу гайдов расположены установка PWA на
телефон и раскрываемая инструкция «AutoVPN для телевизора» со скачиванием APK.
Предупреждение о стоимости смены IP сохранено.

## Быстрый импорт из PWA

Рядом с подпиской есть кнопка «Открыть в NekoBox». Она передаёт личную ссылку
через `sn://subscription?url=...&name=...`; адрес подписки и название кодируются
отдельно, чтобы символы в имени клиента не меняли параметры импорта.
Рядом с ключом AmneziaVPN есть «Открыть в AmneziaVPN»: передаётся тот же полный
`vpn://` ключ, который доступен для копирования на странице.

Кнопки доступны и в обычном браузере, и в установленной PWA. Приложение должно
быть установлено и поддерживать обработку соответствующей схемы; результат
импорта подтверждается в VPN-клиенте. Если браузер не открыл приложение,
используйте копирование подписки/ключа, QR или APK AutoVPN, который остаётся
доступным. Диплинки не запускаются автоматически и не отправляются посредникам.

Форматы проверены по исходникам клиентов:
[NekoBox manifest](https://github.com/MatsuriDayo/NekoBoxForAndroid/blob/main/app/src/main/AndroidManifest.xml),
[обработка подписки NekoBox](https://github.com/MatsuriDayo/NekoBoxForAndroid/blob/main/app/src/main/java/io/nekohasekai/sagernet/ui/MainActivity.kt),
[AmneziaVPN 5.0.3.0 manifest](https://github.com/amnezia-vpn/amnezia-client/blob/5.0.3.0/client/android/AndroidManifest.xml).
Открытие импорта на реальном телефоне нужно проверить в его браузере и PWA.

Блок смены IP расположен в конце пользовательской страницы. Создание нового
платного сервера — в том числе повторная попытка — требует отдельного подтверждения
с предупреждением о стоимости и влиянии на всех пользователей VPN.

## Android APK

Исходники восстановлены из сохранённого прототипа в [`android-tv/`](../android-tv/README.md).
Версия 0.2.0 поддерживает телефоны в портретной ориентации и TV в горизонтальной,
сохраняет импорт в AmneziaVPN / NekoBox, шифрование привязки и управление пультом.
Это companion для импорта, без собственного VPN-движка.

Подписанный APK находится в `app/static/downloads/AutoVPN-0.2.0.apk` и доступен
с пользовательской страницы. Нужен Android 8+. Для первоначальной привязки
вставьте личную HTTPS-ссылку `/client/{token}` либо `/sub/{token}`.
Для обновления старого debug-прототипа 0.1.0 сначала удалите его и повторите
привязку в release 0.2.0. Удаление companion не удаляет профили в VPN-клиентах.

Ключ выпуска хранится только в исключённом из Git каталоге `data/android-signing/`.
Для последующих APK необходимо сохранить этот ключ; процесс сборки описан
в README Android-проекта. На сервер надо доставлять исходники веб-приложения
и APK, а не каталог с ключом подписи.


## Clash / Mihomo и имена файлов

`/clash/{token}` выдаёт YAML-профиль по образцу с `mixed-port: 7897`, группой
выбора VPN, правилом `MATCH,VPN` и HTTP proxy-provider. Список узлов берётся из
`/clash-provider/{token}` и обновляется раз в час. В нём только включённые
VLESS REALITY и Hysteria2, с текущими параметрами и персональными учётными данными.
Отозванные и отключённые клиенты не получают ни профиль, ни provider.

Имена загрузок: `clash-имяклиента-ревизия.yaml`, `amnez-имяклиента-ревизия.conf`,
`singbox-имяклиента-ревизия.json`. Используется существующая ревизия VPN-конфига;
пробелы и небезопасные символы удаляются, кириллица транслитерируется. Имя
provider и его локальный путь также содержат клиентское имя и ревизию.

«Открыть в клиенте» использует прежний `sn://subscription` без промежуточного
диалога. Профиль Clash скачивается или копируется из отдельного раскрываемого пункта.
Копирование, раскрытие и QR объединены в одну панель; раскрываемые настройки
получили полноразмерные области нажатия и видимый фокус клавиатуры.

Параметры сверены с [VLESS](https://wiki.metacubex.one/en/config/proxies/vless/)
и [Hysteria2](https://wiki.metacubex.one/en/config/proxies/hysteria2/).
У Mihomo есть [ограничение совместимости REALITY с новыми Xray](https://wiki.metacubex.one/en/config/proxies/tls/),
включая используемую проектом ветку 26.7.x. Генерация YAML не подтверждает
реальное соединение: импорт и работу обоих протоколов нужно проверить в клиенте.
Обновление не меняет версию Xray или параметры работающего VPN-сервера.
