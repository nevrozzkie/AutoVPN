# SprintBOX: смена IP заменой бокса

Панель AutoVPN работает на отдельном сервере. В Setup выберите SprintBOX и задайте
API login, API key, имя текущего бокса (`box-…`), код тарифа и код образа ОС.
Если бокса ещё нет, оставьте его имя пустым: появится кнопка «Создать первый бокс».
Текущий IP для первого запуска не требуется. В разделе «Клиенты» должен быть хотя
бы один включённый клиент: его данные используются для проверки VPN до публикации IP.
Пустое поле API key при повторном сохранении сохраняет существующий ключ.
Секретный ключ не отображается в формах, списках боксов и журнале.

Для новой машины требуется SSH `root:22` по приватному ключу без парольной фразы.
В Setup укажите путь к ключу **на сервере панели**, оставьте пароль SSH пустым,
SSH-хост — пустым либо равным текущему IP VPN. Публичная часть ключа вычисляется
локально и передаётся SprintBOX при создании; приватный ключ провайдеру не передаётся.
ОС для AmneziaWG рекомендуется Ubuntu 24.04, с учётом требований существующего
установщика. Значение кода образа получите из API, не подставляйте название ОС наугад.

Настройки можно задать через окружение:

```dotenv
VPS_PROVIDER=sprintbox
SPRINTBOX_LOGIN=
SPRINTBOX_KEY=
SPRINTBOX_BOX_NAME=
SPRINTBOX_SERVICE=
SPRINTBOX_DISTRIBUTIVE=
```

Сохранённые в Setup значения имеют приоритет над окружением. Для совместимости
существующие установки без выбора провайдера продолжают использовать Aeza.

## Порядок операции

1. Зафиксировать VPN snapshot, провайдера, параметры тарифа/образа и fingerprint
   ключа API. Если имя текущего бокса задано, проверить, что он действительно
   владеет опубликованным IP. При создании первого бокса этот шаг пропускается.
2. Отправить `box/add` с уникальным описанием и публичным SSH-ключом.
3. Дождаться `status/show: finished`, найти ровно один новый бокс с этим описанием
   и единственным новым IPv4. Нельзя выбирать первый появившийся сервер на аккаунте.
4. Дождаться SSH, установить VPN на чистый сервер и применить сохранённый snapshot:
   клиентские UUID, токены и криптографические ключи сохраняются.
5. Выполнить существующие проверки VLESS/Hysteria через новый endpoint.
6. В одной транзакции опубликовать IP и имя нового активного бокса, сбросить
   явно заданный старый SSH-хост, обновить ревизию подписок.
7. Показать на главной странице две кнопки и дождаться решения пользователя.
   Состояние ожидания сохраняется в БД, перезапуск панели его не сбрасывает.

**«Всё ок»** подтверждает, что пользователь проверил VPN. Только после этого
AutoVPN пытается удалить сохранённые старые боксы этой цепочки попыток, дожидается
каждой фоновой задачи и проверяет отсутствие бокса в `boxes/list`. Текущий активный
бокс и посторонние боксы аккаунта не удаляются. Уже удалённые вручную пропускаются.

**«Попробовать другой IP»** создаёт следующий платный бокс и устанавливает VPN,
сохраняя все предыдущие. После установки снова появляются те же две кнопки.
Когда пользователь нажмёт «Всё ок», очистка охватит накопленные старые боксы.
Повторное нажатие старой кнопки и решение для уже сменившегося сервера отклоняются.

При включённом AmneziaWG до нажатия «Всё ок» проверьте handshake клиента через
новый IP. Автоматической полноценной AWG-проверки в проекте нет.
Импортированные статические профили Amnezia нужно обновить для нового адреса.

При явном отказе удаления (включая `41004`, если он реально возвращается) новый
VPN продолжает работать; панель и журнал показывают, какие старые боксы нужно
удалить вручную и почему. Очистка остальных боксов продолжается независимо от
отказа одного из них. Автоматического повторного DELETE нет.
При потере ответа удаления результат считается неопределённым и включается hold.
Перезапуск панели не повторяет создание/удаление с неопределённым результатом.
Оба бокса могут оплачиваться до завершения очистки.

До публикации ошибка сохраняет старые IP и бокс; новый бокс может остаться платным.
Проверьте кабинет и журнал, выполните ручную сверку перед новой операцией.

## Первичный переход с Aeza

Для первого запуска выберите SprintBOX в Setup, заполните API login/key, тариф,
образ ОС и SSH-ключ. Поле текущего бокса оставьте пустым. На главной нажмите
«Создать первый бокс», проверьте параметры и подтвердите создание. Далее идут те
же установка, проверка, публикация IP и две кнопки выбора, что и при обычной смене IP.

Если старых боксов нет, «Всё ок» просто завершает настройку без запросов удаления.
«Попробовать другой IP» создаёт следующий бокс и сохраняет первый; после проверки
нового кнопка «Всё ок» предложит очистить накопленные старые боксы.

При переходе с Aeza оставьте прежний IP до успешного завершения новой установки:
первый бокс SprintBOX публикуется только после проверки. VPS Aeza и посторонние
боксы аккаунта не добавляются в список удаления. Старый VPS Aeza удаляется отдельно
после проверки. Панель работает на отдельном сервере.

## Контракт и проверка

Используется опубликованный API: `https://api.from.sh/sprintbox/`, POST form data,
заголовки `AUTH-LOGIN` и `AUTH-KEY`. Создание, перезапуск и удаление возвращают ID
асинхронной задачи. Тарифы: `services/list`, образы: `distributives/list`.
Публичная документация не описывает отдельный параметр локации для `box/add`:
до использования подтвердите локацию выбранного тарифа/поведение API в аккаунте.
Интеграция не подставляет недокументированный параметр location.

Источники: [API](https://api.sprintbox.ru/),
[ключ API](https://cp.sprintbox.ru/customer/api/index).
Ответ `box/show` содержит VNC credentials, поэтому сырые ответы не выводятся в UI.

Локальные проверки используют mock API и тестовую БД. Живые создание, списание
денег, удаление, SSH-деплой и импорт клиентских профилей требуют отдельной проверки
с выбранным тарифом и учётными данными. При разработке эти действия не выполнялись.
